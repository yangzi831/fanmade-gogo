# 物料发布、现场发放与分享：当前实现

日期：2026-10-14。保留共享活动库；物料、库存、草稿、预约和现场登记属于各制作人。所有管理接口在后台检查归属，管理员维护活动资料的权限不包含其他制作人的私密信息。

## 如何试用

按 README 启动，访问 http://localhost:3001。演示账号 `wuwei` / `xiaoyu`，密码均为 `Demo2026!share`。演示操作会真实保存，正式环境不要导入 seed。

1. 进入工作台，搜索并选择已有活动；没有时核对相似活动后添加。管理员也可先在“管理全站活动库”录入空活动。
2. 进入“我的物料与库存”，点“连续添加物料”。编辑一件后点“＋ 连续添加一件”，不用重新选择活动、重复进入发布流程。一次最多 50 件。
3. 填写图片、名称、简介、类型、数量、每人限领、领取方式、领取说明；尺寸、材质、截止时间选填。电脑右侧实时预览，手机使用“切换发布前预览”。
4. “保存全部为草稿”写入服务器，关闭、刷新后用“继续编辑草稿”恢复；“发布本次 N 件物料”整批发布。任何一件数据有误，整批不保存、不部分发布。
5. 在已公开清单中发布第一件公开物料后，尚未结束的活动自动出现在首页。纯草稿、空活动仍可通过活动搜索找到。
6. 在物料行暂停／恢复，或编辑截止时间和说明。截止后已有预约仍在“我的预约与互换”，继续核对后标记领取。
7. 无线上预约的现场发放使用“手动登记发放／互换”；已有预约使用“标记已领取”。现场登记支持多件物料，昵称、联系方式、地点、备注均可留空。
8. 勾选后台物料后点“分享清单／已选 N 件”，选择完整清单、部分或单件，切换三种配色并编辑短说明。下载 PNG、复制链接或复制文案。公开制作人清单和单件详情也有分享入口。

## 草稿和开放状态

- 草稿与图片保存到服务器数据库／磁盘，不依赖浏览器本地缓存；上传未保存表单时，图片会留在服务器，暂不自动清理未引用上传。
- 草稿不出现在公开活动、个人主页和公开图片访问中，不能新建预约。对已发布物料选择“保存全部为草稿”会暂时隐藏它，界面明确提示；已有预约、预留库存保留。
- 名称发布时必填，图片可留空使用默认示意图；类型为贴纸、明信片、徽章、应援牌、其他。旧数据不能明确推断时默认“其他”，制作人可修改。
- 截止时间按编辑设备时区输入，后台保存带时区的绝对时间；到点立即由服务器拒绝新免费预约和新互换申请。无需定时任务，不释放已有预约。
- 状态展示优先级为草稿 → 已截止 → 已暂停 → 已领完／领取方式。库存数独立显示；已截止可以仍有库存，恢复暂停不会越过截止时间。
- 暂停、截止、转草稿不取消已有预约；制作人仍可接受之前的互换申请（再次检查库存）、取消预约或核销。活动结束仅影响首页发现，物料截止另行设置。
- 总量不能小于已预留与已领取之和。修改总量、说明、图片不改变原预约数量和物料 ID。

## 现场登记与库存

| 操作               | 可用库存 | 已预留 | 已领取 |
| ------------------ | -------- | ------ | ------ |
| 免费预约成功       | 减数量   | 加数量 | 不变   |
| 互换申请待确认     | 不变     | 不变   | 不变   |
| 确认线上互换       | 减数量   | 加数量 | 不变   |
| 取消已预留预约     | 加数量   | 减数量 | 不变   |
| 核销已有预约       | 不变     | 减数量 | 加数量 |
| 现场手动发放／互换 | 减数量   | 不变   | 加数量 |

手动登记只能使用自己的、已发布且支持对应领取方式的物料。每件都检查 `总量 - 已预留 - 已领取`；任一不足整单失败。事务与线上预约共用同一数据库写锁，多个进程争抢最后一份也不会超额。每次提交有幂等键，网络重试不重复记账。

默认现场登记表示已经完成当面交付，因此允许物料在暂停或截止后登记，不受线上每人限领数量限制；草稿不允许登记。现场联系方式不公开，不参与免登录预约限领累计。现阶段不提供撤销现场登记、部分核销、撤销领取和库存流水导出。应先核对实物数量再提交。

## 分享范围与有效性

| 分享内容           | 公开目标                       | 内容规则                                                      |
| ------------------ | ------------------------------ | ------------------------------------------------------------- |
| 制作人本场完整清单 | `/e/活动ID/by/用户名`          | 显示当前所有已公开物料；以后发布的新物料自动加入              |
| 部分清单           | `/s/随机分享ID`                | 数据库只保存所选原物料 ID，不复制库存；以后新增物料不自动加入 |
| 单件物料           | `/e/活动ID/by/用户名/m/物料ID` | 显示该制作人在该活动的原物料详情                              |

所有链接实时读取原物料库存，预约仍按同一活动、同一制作人提交。部分清单的物料被转草稿后从公开结果中排除，重新发布同一 ID 后恢复；关闭制作人清单或站点隐藏活动后公开链接不可访问。单纯修改库存、名称或说明不会使链接失效。

PNG 包含头像／昵称、活动名称／日期／场次／城市、前 4 件缩略图与名称、领取方式、生成时数量、简短说明、站名和二维码。超过 4 件提示查看完整清单。图片始终完整放入预览框，不裁切作品。长标题和说明按限定行数省略，完整内容在网页中查看。

二维码使用黑白像素、四模块留白和整数缩放，不覆盖装饰。二维码指向该次公开范围，不能使用后台或私密预约查询链接。三种配色不改变黑白二维码。

## 验证与真实设备待验收

- 已通过 21 组接口／迁移测试；新测试覆盖草稿隔离、整批原子发布、截止／暂停、手动库存、两进程并发、幂等、旧预约领取和三种分享范围。
- 浏览器已连续添加两件不同纵横比图片、保存草稿、刷新恢复、整批发布；完成免费现场发放、现场互换、单件详情预约和后台领取。联调使用独立临时数据库，没有添加到现有业务库。
- 浏览器检查 320、390、768、1024、1440 像素宽度的活动页、管理库存、单件详情、发布和分享窗口；页面与弹窗内容均无横向溢出。已检查桌面和手机截图，图片完整展示。
- 已从“保存分享图片”实际下载三种 PNG，用 `jsqr` 解码并请求目标公开接口，确认活动、制作人和选中物料范围；复制链接、复制介绍加链接均正确。
- 复验命令：`node scripts/verify-share-cards.mjs 输出图片路径.png`。需要运行对应站点，且安装开发依赖；示例测试图片中的临时站点地址在测试服务关闭后不可访问。
- **尚未完成真实微信长按识别、iOS／Android 相册保存和浏览器兼容性验收。** 当前环境没有实体手机／微信客户端，二维码自动解码不能替代微信实测。
- 正式验收应在公网 HTTPS 域名（或手机可访问的同一局域网地址）打开网站生成卡片，保存原 PNG，在微信打开图片并长按识别，分别检查完整／部分／单件目标及实时库存；再检查微信转发压缩后的识别效果。`localhost` 指向扫码设备自身，不能用于异机验收。

## 持久化与上线

新增字段、手动登记表和分享范围表通过 `PRAGMA user_version=2` 自动迁移。首次升级非空物料库时生成 `data/before-material-studio-时间戳.sqlite` 快照，保留已有 ID、预约和库存。仍需同时备份数据库与上传目录。

无需新增外部图片、二维码或认证服务。上线仍按 [DEPLOYMENT.md](DEPLOYMENT.md) 使用持久化服务器与 HTTPS，配置访问来源。当前未发布到公网。
