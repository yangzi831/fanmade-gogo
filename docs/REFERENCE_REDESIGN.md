## 活动、收藏和页面规则

- `events` 新增 `kind`、`poster`、`featured`。活动分类是独立业务字段，默认“其他”，不会按海报配色或名字自动判定。管理员活动表单和新活动表单都可选择分类。仅已知演示剧场活动显式标记“音乐剧”。
- CAN 正式名称为 **楠溪江·2026 Can Festival PT.2**，日期按海报 **2026-10-16 至 2026-10-18**；城市“温州”、场地暂填“楠溪江”、场次“全天”、结束时间默认 23:59（北京时间）。精确场地地址、实际结束时间可由管理员后续补充。
- CAN 为真实活动记录、非演示活动，初始 0 制作人 / 0 公开物料。首页独立“精选活动”区域允许展示已收录但尚未有物料的活动；默认活动目录继续只展示尚未结束、有公开物料的活动。搜索包含空活动和已结束活动。
- 精选横幅读取 `/api/featured-events`，只展示公开且尚未结束的精选记录；按精选优先级排序。当前只有 CAN，未做假轮播。可重复运行 `npm run feature:can` 安装该活动，依据名称、城市、场地、日期和场次组合定位，不按名称单独合并。
- `user_favorites` 按账号持久化保存 material / event / creator 的引用，PUT / DELETE 可重复重试。爱心表示收藏，未实现独立点赞计数。“关注的活动”就是收藏的活动，不涉及社交关注或通知。
- 收藏必须登录，浏览不强制登录。收藏不复制库存、不占库存；收藏的数据接口必须登录，只返回本账号保存的数据。未公开的物料不会通过收藏接口泄漏。
- 管理入口预览展示自己已公开的物料，草稿在原独立管理页查看。待处理徽标目前按真实 `pending` 申请计数；现有免费预约直接待领取，不能把它伪装成新的待确认状态。
- 双向记录和管理区“收到的申请”仍读取同一张预约表。桌面选择详情无额外库存操作。手机 `/records/:id` 使用服务端参与方鉴权，不用领取码获取私密数据。历史访客私密查询链接保留。
- 原领取流程、累计联系方式限额、互换接受后预留、取消释放、交接完成、并发防超卖与幂等规则本轮保持。卡片写“限领”，不把旧累计限制宣称为新的每次限制。
- 图中“联系制作人”暂映射为查看发布者公开主页。发布者可查看获授权的申请人联系方式；没有新建聊天系统或未经授权发送消息。

2. 隔离的本地 QA 后台（3002，临时 SQLite）连接两个独立 Playwright 浏览器：分别登录 `wuwei` 与 `xiaoyu`。无为收藏后，小屿的收藏为空；不是各浏览器 localStorage 模拟。
3. 浏览器提交一条领取和一条互换测试申请：小屿在新记录页接受互换、标记已交换；无为在手机详情取消普通领取。互换完成后总量 32 / 预留 1 / 已送出 1 / 可用 30，随后取消领取释放剩余预留。两边刷新可查看同一状态。
4. 在活动搜索中找到空 CAN，收藏活动、进入“发布第一份物料”，表单正确关联 CAN；使用表单发布测试贴纸后，默认活动目录出现 CAN，物料发现流可按“后摇”找到新作品。测试只写临时库，没有写主站预约或库存。
5. 发现、活动、我的、记录、管理、发布、CAN 活动详情、公开主页和账号记录详情在 **320 / 390 / 768 / 1024 / 1440 px** 共 45 个页面宽度组合检查，均无横向溢出；保留桌面、手机和平板截图于 `output/playwright/reference-*.png`。完整海报弹层实际打开通过。Playwright 验证搜索、爱心、发布入口和交接按钮能操作。
6. 主站迁移前自动生成 `before-discovery-时间戳.sqlite`。核对迁移及 CAN 导入前后：已有 **3 个账号、7 件物料、2 条预约、0 条现场登记** 保留，每件物料的 total / reserved / collected 完全相同；活动从 4 条变为 5 条，仅增加 CAN。尊重用户已有新增账号与活动。

浏览器自动检查不等于微信或真实手机验收：iOS / Android 手势、微信内置浏览器、长按分享二维码识别仍待真实设备测试。本轮没有改写已有分享卡生成逻辑。
